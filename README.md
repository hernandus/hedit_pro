# Hedit Pro 🎬

**Hedit Pro** is a high-performance, open-source Non-Linear Video Editor (NLE) for Linux inspired by **Adobe Premiere Pro**. Built with **Python 3**, **PySide6 (Qt6)**, and **MLT Multimedia Framework**.

## 🚀 Features (In Development)
- **Premiere Pro Dockable Workspace**: Customizable, multi-panel workflow.
- **Dual Monitor Setup**: Source Monitor (In/Out trimming) & Program Monitor (Sequence preview).
- **Multi-Track Timeline**: Selection, Razor, Ripple, Slip, and Slide editing tools.
- **Color Grading**: Lumetri-style color controls, RGB curves, and 3D LUT support.
- **Background Exporting**: Fast, non-blocking rendering using MLT `melt`.

## 🛠️ Stack
- **Language**: Python 3
- **GUI Framework**: PySide6 (Qt6)
- **Multimedia Engine**: MLT Framework (`python-mlt` & `melt`)
